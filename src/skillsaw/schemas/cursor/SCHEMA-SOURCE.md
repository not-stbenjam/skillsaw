# Cursor packaging schemas

Fetched 2026-09-18 from [cursor/plugins](https://github.com/cursor/plugins/tree/032be146865d973682535de75f2287da438550bf/schemas).
The JSON files are unchanged upstream snapshots. The validator accepts the
additional marketplace entry fields and object sources documented in the
[Cursor reference](https://cursor.com/docs/reference/plugins), which is broader
than the repository publication schema. Unknown fields remain allowed to avoid
rejecting forward-compatible metadata.
